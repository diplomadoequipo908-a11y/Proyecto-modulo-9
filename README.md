# Instrucciones de Archivo análisis.rmd

1. Descargue la carpeta Data. cuadrantes.csv, analisis.rmd y descargue Carpetas de Investigación (acumulado 2016-2024)
CSV en la página https://datos.cdmx.gob.mx/dataset/carpetas-de-investigacion-fgj-de-la-ciudad-de-mexico
2. cree un folder con todos los archivos descargado
3. Renderizar el proyecto
4. Tendrá acceso a un html que se ve así: https://rpubs.com/DavidSL/fgj_cdmx_2016_2024
